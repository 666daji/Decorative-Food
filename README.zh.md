## 简介

**TW的装饰性食物** 是一款轻量、贴合原版风格的模组，让食物可以作为 **3D 方块** 放置到世界之中。把苹果放在桌上、把面包叠起来、或在台面上留一碗炖菜——所有模型都保持原版像素艺术风格，与你的建筑自然融为一体。

它**不新增任何游戏规则**，也不干扰原有玩法。原版食物仍然是真实的物品，只是变得可以摆放、可以堆叠。

## 特色

- **把任意食物当作方块放置**——手持物品，右键点击某个表面，就像放普通方块一样。
- **可堆叠食物**——潜行右键点击已放置的食物堆，用相同的食物即可再叠加一个；每种食物有各自的堆叠上限（如苹果最多 5 个、饼干最多 7 个）。
- **潜行交互**——潜行时仍能对食物方块添加 / 取出，堆叠操作不会被放置操作打断。
- **原版美术风格**——模型与纹理刻意贴合原版我的世界观感。

## 支持的食物

以下原版物品可以放置与堆叠（总计超过 45 种）：

- **零食：** 曲奇、苹果、西瓜片、面包、干海带
- **蔬菜：** 甜菜根、马铃薯、烤马铃薯、毒马铃薯、胡萝卜、甜浆果、发光浆果
- **金制食物：** 金苹果、附魔金苹果、金胡萝卜、闪烁的西瓜片
- **肉类：** 生鸡肉、熟鸡肉、生牛肉、熟牛肉、生羊肉、熟羊肉、生猪排、熟猪排、生兔肉、熟兔肉
- **鱼类：** 生鳕鱼、熟鳕鱼、生鲑鱼、熟鲑鱼、河豚、热带鱼
- **炖菜与碗：** 兔肉煲、蘑菇煲、甜菜汤、可疑炖菜、碗
- **桶：** 桶、水桶、奶桶、岩浆桶
- **其他：** 南瓜派、紫菘果、鸡蛋、蜘蛛眼、不死图腾、药水瓶、蜂蜜瓶

## 使用方式

1. **放置**——手持食物物品，右键点击某个表面（如地面或桌面）。
2. **堆叠**——潜行右键点击已放置的食物，手持**相同**物品即可再叠一个，直到该食物的堆叠上限。
3. **取出**——潜行右键点击食物堆，手持其他任何物品或空手即可取回一个。
